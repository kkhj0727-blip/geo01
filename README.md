## 클라우드 개발 환경

2026년 10월 31일 기준으로 클라우드 환경에서 다음 항목을 확인했습니다.

- 저장소 위치: `/workspace/geo01`
- 기본 브랜치: `main`
- 기존 플랫폼 인증과 HTTPS 프록시를 통한 GitHub 저장소 읽기 접근 성공
- 사용 가능한 도구: Git 2.52.0, Python 3.12.14, Node.js 24.19.0, npm 11.9.0

현재 저장소에는 이 문서만 있으며, 애플리케이션 코드나 의존성, 빌드 및
테스트 설정은 없습니다. 따라서 추가 패키지 설치는 필요하지 않으며,
애플리케이션 실행·빌드·테스트는 아직 검증할 대상이 없습니다.

## 개발 시작

기존 체크아웃인 `/workspace/geo01`에서 작업합니다. 각 클라우드 작업은
격리된 환경에서 실행되므로 별도 요청이 없다면 Git worktree를 만들 필요가 없습니다.

```sh
cd /workspace/geo01
git status --short --branch
```

프로젝트 코드와 의존성 설정을 추가하면 해당 기술 스택에 맞는 설치,
실행 및 테스트 절차를 이 문서에 기록합니다. 현재 별도의 설치 스크립트나
서비스 시작 절차는 필요하지 않습니다.
